# 佩里科岛武器箱刷新系统 - 使用说明

## 🎯 系统概述

武器箱刷新系统允许在佩里科岛的30个固定点位刷新武器箱，玩家可以搜索箱子获得随机武器和物资。玩家死亡后将退出活动。

---

## 📋 系统架构

### 1. **文件结构**
```
server/
  - weapon_boxes.lua     # 服务端逻辑（生成、刷新、锁定）
client/
  - weapon_boxes.lua     # 客户端逻辑（实体生成、交互）
config.lua              # 配置文件（包含武器箱配置）
```

### 2. **核心功能**
- ✅ **30个固定刷新点**：分布在佩里科岛各个区域
- ✅ **加权随机掉落**：根据权重随机选择武器/物资
- ✅ **防并发锁定**：同一箱子同时只能被一个玩家搜索
- ✅ **进度条动画**：8秒搜索动画（可中断）
- ✅ **ox_target交互**：靠近箱子后显示交互选项
- ✅ **开箱后消失**：搜索后箱子立即消失，避免重复拾取

## ⚙️ 配置说明

### **武器箱配置** (`Config.WeaponBoxes`)

```lua
Config.WeaponBoxes = {
    enabled = true,  -- 总开关（改为false禁用系统）
    
    prop_model = 'prop_box_ammo03a',  -- 武器箱模型
    
    spawn_points = {  -- 30个刷新点位
        {coords = vector3(4438.41, -4482.21, 3.41)},
        -- ... 更多点位
    },
    
    interaction = {
        distance = 2.5,              -- 交互距离
        label = '搜索武器箱',        -- 交互文本
        icon = 'fas fa-box-open',    -- 图标
    },
    
    progress = {
        duration = 8000,             -- 搜索时长（毫秒）
        label = '正在搜索武器箱...',
        canCancel = true,            -- 是否可取消
    },
    
    loot_table = {  -- 掉落物品池（加权随机）
        {item = 'weapon_sawnoffshotgun', min = 1, max = 1, weight = 20},
        {item = 'weapon_g17tan', min = 1, max = 1, weight = 30},
        {item = 'pistol_ammo', min = 1, max = 3, weight = 18},
        {item = 'shotgun_ammo', min = 1, max = 3, weight = 12},
        {item = 'armor', min = 2, max = 3, weight = 20},
    },
    
    debug = true,  -- 调试模式（显示详细日志）
}
```

## 🎮 使用流程

### **活动启动时**

1. **管理员开启系统**
   ```
   island_toggle
   ```

2. **玩家报名**
   - 前往机场报名点
   - 与NPC交互报名

3. **管理员启动活动**
   ```
   island_status start
   ```

4. **武器箱自动刷新**
   - 控制台显示：`[yx_Island] 武器箱系统已初始化，共生成 30 个武器箱`

### **玩家拾取武器箱**

1. **寻找武器箱**
   - 武器箱模型：`prop_box_ammo03a`（弹药箱）
   - 分布在佩里科岛30个固定点位

2. **靠近交互**
   - 靠近武器箱（2.5米内）
   - 出现 ox_target 交互提示："搜索武器箱"

3. **搜索动画**
   - 点击后开始8秒搜索进度条
   - 动画：蹲下搜索
   - **可按ESC取消**

4. **获得物品**
   - 根据权重随机获得一件物品
   - 通知：`获得: xxx x数量`
   - 箱子立即消失

5. **背包已满**
   - 提示：`背包空间不足`
   - 箱子锁定被释放，可以再次尝试

## 📊 系统生命周期

### **初始化**
```lua
-- server/activity.lua (StartIslandActivity)
local boxCount = exports['yx_Island']:InitializeWeaponBoxes()
```

### **清理**
```lua
-- server/main.lua (ResetIslandSystem)
exports['yx_Island']:ClearAllWeaponBoxes()
```

### **事件流**

```
[活动开始]
    ↓
InitializeWeaponBoxes()
    ↓
生成30个武器箱实体
    ↓
TriggerClientEvent('yx_island:client:spawn_weapon_box', -1, ...)
    ↓
[客户端] 创建实体 + ox_target 交互
    ↓
[玩家] 靠近并交互
    ↓
TriggerServerEvent('yx_island:server:open_weapon_box', box_id)
    ↓
[服务端] 验证 + 锁定 + 触发进度条
    ↓
TriggerClientEvent('yx_island:client:start_weapon_box_progress', source, box_id)
    ↓
[客户端] lib.progressBar() 8秒动画
    ↓
TriggerServerEvent('yx_island:server:complete_weapon_box_search', box_id)
    ↓
[服务端] 选择随机物品 + 给予玩家 + 删除箱子
    ↓
RemoveWeaponBox(box_id)
    ↓
TriggerClientEvent('yx_island:client:remove_weapon_box', -1, box_id)
    ↓
[客户端] 删除实体
```

## 🚨 常见问题

### 1. **武器箱不刷新？**
**检查项：**
- `Config.WeaponBoxes.enabled = true`
- 活动是否已启动（`island_status start`）
- 控制台是否有错误

### 2. **无法交互武器箱？**
**检查项：**
- `ox_target` 是否正常运行
- 交互距离是否太远（默认2.5米）
- 箱子是否已被其他玩家搜索

### 3. **搜索后没有物品？**
**检查项：**
- 背包是否已满
- `loot_table` 配置是否正确
- 物品代码是否存在于 `QBCore.Shared.Items`

### 4. **活动结束后箱子不消失？**
**检查项：**
- `server/main.lua` 的 `ResetIslandSystem()` 是否调用了 `ClearAllWeaponBoxes()`
- 客户端是否收到 `yx_island:client:remove_weapon_box` 事件

## 🔥 性能优化

1. **实体优化**
   - 武器箱实体使用 `FreezeEntityPosition` 冻结，避免物理计算
   - 活动结束后立即清理所有实体

2. **防并发**
   - 使用 `BoxLocks` 表锁定机制，避免同时搜索冲突
   - 玩家掉线自动释放锁

3. **网络同步**
   - 所有客户端共享同一批实体
   - 搜索后所有客户端同步删除实体
